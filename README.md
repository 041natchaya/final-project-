# MoodFlow - ระบบสุ่มเพลงและกิจกรรมตามอารมณ์ 🎵

**MoodFlow** เป็นโปรเจกต์พัฒนาเว็บไซต์แอปพลิเคชัน (Web Application) ที่ออกแบบมาเพื่อรับฟังความรู้สึกของผู้ใช้งาน และนำเสนอเพลงที่เหมาะสมกับอารมณ์ในขณะนั้น เพื่อช่วยผ่อนคลาย สร้างแรงบันดาลใจ หรือเติมพลังบวกให้กับผู้ใช้งาน

🔗 **ลิงก์เข้าใช้งานเว็บไซต์ (Live Demo):** [https://041natchaya.github.io/final-project-/](https://041natchaya.github.io/final-project-/)

## ✨ ฟีเจอร์หลัก (Key Features)

*   **Smart Mood Engine (ระบบสุ่มเพลงตามอารมณ์):** ผู้ใช้สามารถคลิกเลือกอารมณ์ หรือพิมพ์ความรู้สึกของตัวเองลงไป ระบบจะทำการวิเคราะห์และสุ่มเพลงที่ตรงกับความรู้สึกนั้นมาให้ฟังทันที
*   **Music Library & Search (คลังเพลงและระบบค้นหา):** มีคลังเพลงแนะนำตามหมวดหมู่อารมณ์ และมีช่องค้นหาอัจฉริยะที่เชื่อมต่อกับ **iTunes API** ทำให้สามารถพิมพ์ค้นหาชื่อเพลงหรือชื่อศิลปิน เพื่อดึงข้อมูลเพลงพร้อมหน้าปกอัลบั้มมาแสดงได้แบบ Real-time
*   **Authentication System (ระบบเข้าสู่ระบบ):** ระบบจำลองการยืนยันตัวตนด้วยอีเมลหรือ Google (ผ่าน LocalStorage) โดยมีระบบ **Route Guard** ช่วยปกป้องหน้าเว็บ หากยังไม่ล็อกอินจะไม่สามารถเข้าใช้งานฟีเจอร์ต่างๆ ได้
*   **Dynamic Music Player:** มีเครื่องเล่นเพลงขนาดเล็กในตัว (Mini Player) ที่สามารถกดเล่น, หยุด, และข้ามเวลาได้ พร้อมแสดงหน้าปกอัลบั้มแบบเคลื่อนไหว (Animation)
*   **Responsive Design:** ออกแบบหน้าจอให้รองรับการใช้งานอย่างสมบูรณ์แบบ ทั้งบนเครื่องคอมพิวเตอร์ (Desktop) และโทรศัพท์มือถือ (Mobile)

## 🛠 เทคโนโลยีที่ใช้ (Technologies Used)

*   **Frontend:** HTML5, CSS3 (Vanilla CSS), JavaScript (Vanilla JS)
*   **API Integration:** iTunes Search API (สำหรับการค้นหาเพลง)
*   **State Management:** Web LocalStorage (สำหรับจัดการสถานะการล็อกอิน)
*   **Design & UI:** ระบบ Grid/Flexbox, CSS Animations, Glassmorphism UI
*   **Icons:** FontAwesome 6

## 📂 โครงสร้างไฟล์ (Project Structure)

*   `index.html`: หน้าหลัก (Landing Page) นำเสนอภาพรวมของเว็บไซต์
*   `login.html`: หน้าเข้าสู่ระบบและสมัครสมาชิก
*   `mood.html`: หน้าสำหรับบันทึกอารมณ์และสุ่มเพลง
*   `library.html`: หน้าคลังเพลงและระบบค้นหาผ่าน API
*   `about.html`: หน้าข้อมูลเกี่ยวกับผู้จัดทำ
*   `auth.js`: สคริปต์ควบคุมระบบการล็อกอินและป้องกันการเข้าถึง (Route Guard)
*   `styles.css`: ไฟล์ CSS จัดการความสวยงามหลักของเว็บไซต์
*   `pages.css`: ไฟล์ CSS จัดการ Layout ย่อยของแต่ละหน้า
